# 课灵智学编排平台双赛道作品设计

版本：0.1（待团队审阅）  
日期：2026-10-26  
项目基础：KeLing3.0-main  
产品定位：面向高校学生的 AI 学习目标规划、知识检索、任务执行与进度复盘平台

## 1. 项目背景与目标

现有课灵项目已经具备课程、任务、笔记、知识图谱、账号和持久化数据能力。当前 AI 对话主要由后端直接调用 DeepSeek，并将工具指令作为文本解析；它还没有围绕 AgentArts 构建可观察的多智能体编排闭环。

本项目把“为某门考试制定两周学习计划，并根据真实完成情况持续调整”作为核心业务。学生提供课程、考试日期、每日可用时间和目标；系统从课程笔记、知识点和已有任务中检索依据，生成有日期、时长、知识点与来源的计划；学生确认后，计划才写入任务表；完成任务后，复盘流程根据真实完成记录给出调整建议。

同一套核心系统支持两种参赛表达：

- **华为 ICT 创新赛赛题二 AgentArts**：重点证明 AgentArts 上的 Agent、工作流和多 Agent 协作确实承担了请求路由、知识接入、任务规划和运行观测。
- **辽宁省创新赛 AI+鸿蒙**：重点按本地附件4、附件5说明端—云—智架构、交互界面、真实后端数据库、AI 能力和业务闭环。首轮交付为 Web/PWA，不将现有 Android 客户端称为 HarmonyOS 应用；目前没有设备和 DevEco 环境，因此不承诺原生 HarmonyOS 工程或实机结果。

省赛附件3要求纯软件作品具有可交互前端、真实云端数据持久化和实际 AI 接入，并鼓励 HarmonyOS 应用端。无设备时，交互式 Web/PWA 可作为当前可验证的端侧方案，但不能据此宣称已完成原生鸿蒙适配。

## 2. 推荐架构与业务流程

采用“Web/PWA → Express 业务后端 → AgentArts 运行时及 Prisma 数据库”的分层架构。Web 只访问自有后端；AgentArts 凭据保存在服务端环境变量中。后端继续使用现有认证与用户归属校验，为每次请求创建限定用户、课程和能力范围的 AgentRun。AgentArts 通过受限 HTTPS 工具端点按需查询对应资料，客户端不直接发送私有笔记，也不接受模型传入的任意 userId。

主流程：

1. 用户在“智能编排”页面选择课程，输入考试日期、目标和每日可用时间。
2. 后端鉴权、校验课程归属，创建 AgentRun 记录，并生成一次性运行标识。
3. 后端调用配置好的 AgentArts Runtime，只传递用户目标、所选课程的必要标识与一次性运行标识。AgentArts 多智能体控制器路由到知识检索、学习计划或复盘子流程。
4. 知识检索节点通过 AgentArts 知识库读取通用课程资料，并通过受限工具检索当前 AgentRun 所属用户的笔记/知识点和任务摘要；计划节点返回符合结构化 schema 的学习计划；复盘节点比较真实任务完成情况并给出调整建议。
5. 后端解析 AgentArts SSE 事件，将运行节点的名称、类型、状态和耗时发到页面，并保存脱敏后的运行元数据。
6. 页面展示计划草案、来源引用和执行轨迹。用户确认后，后端在数据库事务中创建对应 Task，并记录确认状态。
7. 后续复盘只读取该用户真实完成状态和学习记录。重复确认同一个计划不会生成重复任务。

AgentArts 工作流/智能体调用接口支持 Runtime 调用和 SSE 运行事件；工作流事件能够暴露节点开始、完成、失败和最终输出，足以支撑可视化运行状态。实现时按当前官方接口契约接入，不假定工作台项目名、Runtime 名称、鉴权方式或实时账号额度。参考：[调用工作流/智能体 API](https://support.huaweicloud.com/api-agentarts/InvokeRuntime.html)、[调用响应事件说明](https://support.huaweicloud.com/api-agentarts/agentarts_07_0056.html)。

## 3. AgentArts 应用设计

AgentArts 应用由一个多智能体控制器和三个职责明确的子流程组成：

- **学习请求控制器**：识别学习规划、知识问答、阶段复盘三类请求，处理缺少课程或日期时的追问，并控制流程分发。
- **知识检索 Agent/工作流**：通过 AgentArts 知识库读取团队整理的通用课程材料；通过后端提供的受限检索工具读取当前用户的相关笔记和知识图谱。返回来源标题、类型和片段，不把用户私有笔记放入全体用户共享知识库。
- **计划规划 Agent/工作流**：基于检索依据、课程掌握度、考试日期、可用时长和未完成任务生成结构化的日程草案。
- **复盘 Agent/工作流**：汇总已完成、未完成任务与学习时长，给出下一阶段的补强建议；未经用户确认不改动任务。

AgentArts 输出由后端 schema 校验，包括计划日期、任务标题、说明、预计分钟、课程/知识点引用、优先级和来源。无效或缺引用的输出标记为失败或要求重试，不转成假成功结果。计划创建任务通过独立确认 API 完成，AgentArts 只产生计划建议，不能直接写数据库。

AgentArts 使用的自定义工具需调用可由华为云运行时访问的 HTTPS 后端地址。工具请求使用服务端鉴权和短期、单次运行范围的 runId；后端根据 runId 对应的 AgentRun 记录解析 userId，逐项验证课程归属与允许范围，拒绝由模型直接指定任意 userId。工具只开放课程/知识检索与任务摘要读取，不提供任意 SQL、跨用户查询或无确认写任务能力。上线演示依赖 AgentArts 账号、模型与知识库配置、Runtime 部署，以及运行时可访问的 HTTPS 后端地址。

## 4. 代码组件与数据边界

沿用现有 TypeScript/React、Express、Prisma 和 SQLite/生产 PostgreSQL 配置，不在本轮重写现有登录、课程、笔记、任务和知识图谱模块。SQLite 仅用于本地开发验证；省平台“云端支撑”演示须部署可公网访问的后端，并使用生产 PostgreSQL schema/真实云数据库完成读写验证。现有仓库没有可直接复用的生产密钥，部署还需团队提供可用的云主机/托管数据库配置。

计划新增的后端组件：

- AgentArts Runtime 客户端：调用配置的 Runtime，解析 SSE，统一处理超时、错误与事件。
- 编排 API：创建运行、读取用户自己的运行记录、接收已确认计划。
- 学习资料工具端点：为 AgentArts 提供当前运行范围内的知识检索与任务摘要。
- Prisma 数据模型：AgentRun 保存用户、课程、目标、运行状态、脱敏后的结构化结果、Runtime 执行标识和确认状态；AgentRunEvent 保存节点名、类型、状态、耗时和时间戳；Task 关联其来源 AgentRun/计划序号，以保证重复确认幂等。
- AgentArts 配置：运行时 URL/名称和鉴权凭据从服务端环境读取；前端不接收云端密钥。缺少配置时返回明确的“未配置 AgentArts”，不静默切回本地模型或静态示例。

计划新增的 Web 页面：

- 独立的“智能编排”入口，不破坏现有 AI 助手。
- 学习目标表单、运行中节点时间线、计划草案、来源引用、确认入库和复盘记录。
- 运行详情从真实 API/数据库读取，页面刷新后可继续查看。
- 展示节点和工具的公开状态，不展示模型内部推理内容；日志避免保存完整私有笔记、密钥或未脱敏的请求体。

数据规则：

- 所有课程、笔记、知识点、任务和运行记录都按 JWT 的 userId 校验归属。
- 共享 AgentArts 知识库只放可公开/团队获准的课程资料，不放学生个人信息。
- 个人笔记由本地后端按当前用户范围检索，向模型传递最少相关片段及来源。
- 确认计划时先验证运行归属、运行成功状态、结构化输出与计划项数量，再以事务创建 Task。
- 运行追踪仅保存业务所需的脱敏事件元数据；不保存 reasoning_content 或完整工具输入输出。

## 5. 失败处理与验证

- AgentArts 凭据、Runtime 或服务端 HTTPS 工具地址缺失：明确报告配置状态；不伪造运行轨迹或成功计划。
- AgentArts 超时、SSE 中断或 Runtime 报错：标记 AgentRun 失败/中断，保存可恢复的事件摘要；用户可重试，不生成任务。
- 结构化输出校验失败：不展示确认按钮，不写入任务表。
- 任务确认重复提交：以 AgentRun/计划项唯一关联或事务状态保证幂等，返回已有任务。
- AgentArts 工具请求的 runId 无效、过期、越权或课程不属于该用户：拒绝请求并记录安全事件。

开发验证范围：

- Web 与 server TypeScript 构建、Web lint。
- SSE 解析、AgentArts 错误/超时处理、计划 schema 校验、运行状态转移与错误提示。
- 越权测试：用户 A 无法读取用户 B 的课程资料或运行记录。
- 幂等测试：同一 AgentRun 重复确认不会重复创建 Task；失败运行无法确认。
- 知识检索测试：仅返回当前用户和所选课程可见的笔记/知识点，并保留来源标识。
- 连接真实 AgentArts Runtime 后执行完整端到端验收：检索、计划、多 Agent/工作流事件、确认、数据库落库、刷新后读回与复盘。未完成真实平台配置前，只能报告代码层测试结果，不能声称线上 AgentArts 闭环已验证。

## 6. 两套材料与交付包

华为赛题二材料单独放入 `submission/agentarts`：

- 作品简介、创意点、团队介绍、行业问题与落地场景。
- AgentArts Agent/Workflow 结构、工具说明、知识库来源、输入输出 schema 和部署调用说明。
- 可运行操作手册、证据截图清单、约 3–5 分钟演示视频脚本。
- AgentArts 运行前置条件清单，包括需由团队提供的 Runtime 名称、鉴权配置和可公开访问的部署地址。

辽宁省平台材料单独放入 `submission/liaoning`：

- 按附件4模板填写的需求文档副本。
- 按附件5模板填写的技术设计文档副本。
- 项目 README、端—云—智架构图、业务闭环图和约 3–5 分钟演示脚本。
- 按平台要求整理的报名表/汇总表副本及源代码包或仓库链接说明。

现有“省赛要求”目录和已填写报名原件保持不变。只有从原模板复制出的工作副本用于编辑。团队成员、学校、指导教师和联系方式等事实性信息沿用原表或留给团队核对；不凭空编造。视频脚本与录制清单可以准备，视频文件需由团队录制和复核后加入提交包。

本轮范围不包括原生 HarmonyOS ArkTS/HAP 应用、真实硬件接入、HarmonyOS 实机演示、未经团队核对的成员信息，以及声称已部署但尚未从 AgentArts 控制台读回的配置。若后续提供 HarmonyOS 设备和 DevEco 环境，可单独扩展端侧工程与验证。
